# Optativa 3 - Ciencia de Datos

Repositorio para la materia **Optativa 3: Ciencia de Datos**.

## Práctica 1: Entorno Profesional y Exploración Inicial

### Contenido del Repositorio
- `semana01_exploracion.ipynb`: Jupyter Notebook con la carga, exploración estadística y visualización de histograma de ventas de videojuegos.
- `video_games_sales.csv`: Dataset derivado de Kaggle con los títulos más vendidos globalmente.
- `distribucion.png`: Gráfico generado con Matplotlib que muestra la distribución de la primera variable numérica (`Rank`).
- `requirements.txt`: Dependencias del proyecto (`numpy`, `pandas`, `matplotlib`, `jupyter`).
- `.gitignore`: Configuración de archivos excluidos del control de versiones (ej. `.venv`).

### Instrucciones para Ejecutar
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/optativa3-ciencia-datos.git
   cd optativa3-ciencia-datos
   ```
2. Crear y activar entorno virtual:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   # source .venv/bin/activate
   ```
3. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
4. Abrir VS Code e iniciar Jupyter Notebook:
   ```bash
   code .
   ```
